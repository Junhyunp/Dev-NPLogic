 - 데이터디스크 업로드 시 시트별로 일련번호를 기준으로 좌측 열, 위측 행들 모두 제거한 후 컬럼명 추출하고 공백을 모두 제거 -> 매핑 -> 1차 매핑 실패한 경우 평가자가 직접 매핑할 수 있게

 - 차주일반정보: 자산유형이 R/S 일수도 있고 Regular/Special 일 수도 있음 -> Regular/Special로 통일

 - 채권일반정보: 대출일련번호가 숫자인 경우 -> "차주일련번호-대출일련번호" 문자열로 표출
 - 채권일반정보: 정상 이자율 컬럼만 선택되고 연체 이자율 컬럼이 없는 경우 -> 연체 이자율 = 정상이자율 + 3%
 - 채권일반정보: 연체 이자율 컬럼만 선택되고 정상 이자율 컬럼이 없는 경우 정상 이자율 = 연체이자율 - 3%
 - 채권일반정보: 채권액 합계 컬럼 없음 -> "채권액 합계"는 "환산된 대출 잔액" + "가지급금" + "미수이자"로 계산

 - 물건정보: 선순위 소액보증금 없음-> 선순위 소액보증금 = 선순위 주택 소액보증금 + 선순위 상가 소액보증금
 - 물건정보: 선순위 임차보증금 없음 -> 선순위 임차보증금 = 선순위 주택 임차보증금 + 선순위 상가 임차보증금

 - 신용보증서: 계좌일련번호가 여러개의 숫자로 이루어진 경우 각각의 숫자로 분류 필요 -> "차주일련번호_계좌일련번호" 문자열로 표출
 - 신용보증서: 계좌일련번호가 하 숫자로 이루어진 경우 -> "차주일련번호_계좌일련번호" 문자열로 표출

 - (NH, SHB) 회생차주정보: 상장/비상장 -> 비상장/상장/공백 문자열 추출, 종업원수 00명(~~~) -> 00명만 추출
