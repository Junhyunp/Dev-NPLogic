## 비핵심조서양식/ 폴더 - 비핵심자산 조서 양식 및 샘플

### 비핵심조서란?
**비핵심조서(Non-Core Asset Report)**는 부실채권(NPL) 평가 과정에서 작성하는 핵심 문서입니다.
각 물건/차주별로 다음 내용을 체계적으로 정리합니다:
- 차주 정보 및 채권 현황
- 담보물건 상세 정보
- 권리분석 결과 (선순위 채권, 임차인, 당해세 등)
- 감정평가 및 시세 분석
- 회수전략 및 시나리오별 XNPV 계산
- 최종 평가 의견

### 데이터디스크 업로드 기능 개발 시
1. **읽기 순서**:
   - `01. 대표시트명, 대표컬럼명.txt` - 필수 컬럼 파악
   - `03. mapping_template.json` - 매핑 구조 이해
   - `02. 데이터디스크 업로드시 고려사항.txt` - 예외 처리 규칙
   - 은행별 샘플 파일 - 실제 형식 확인

2. **테스트 전략**:
   - 각 샘플 파일로 파싱 테스트
   - 매핑 누락 컬럼 검증
   - 데이터 타입 변환 확인 (날짜, 금액, 텍스트)
   - DB 저장 성공 여부 확인

3. **예외 처리**:
   - 컬럼명 변형 (공백, 특수문자)
   - 병합 셀 처리
   - 빈 행/빈 셀 처리
   - 형식 불일치 시 기본값 적용
   - 오류 로그 상세 기록

### 비핵심조서 기능 개발 시
1. **조서 데이터 소스**:
   - 차주 정보: `borrowers`, `borrower_restructuring` 테이블
   - 채권 정보: `loans`, `credit_guarantees` 테이블
   - 물건 정보: `properties` 테이블
   - 권리분석: `right_analysis` 테이블
   - 평가 정보: `evaluations` 및 관련 테이블
   - 경매/공매: `auction_schedules`, `public_sale_schedules` 테이블

2. **조서 출력 기능**:
   - 양식 참고: `비핵심조서양식/SHB 2025-8 Poo A-비핵심조서-양식-V1-수정.xlsx`
   - ClosedXML 또는 EPPlus 라이브러리 사용
   - 템플릿 기반 출력 (양식 복사 후 데이터 채우기)
   - 수식은 값으로 변환하거나 C# 로직으로 재계산

3. **관련 화면**:
   - `NonCoreView.xaml` - 비핵심자산 관리 메인 화면
   - `PropertyDetailView.xaml` - 물건 상세 (조서 데이터 원본)
   - `LoanSheetView.xaml` - 채권 시트
   - `RightsAnalysisTab.xaml` - 권리분석 탭

### UI 개발 시
1. **디자인 일관성**:
   - MaterialDesignThemes 스타일 유지
   - 색상: 기존 `ColorZone`, `Card` 스타일 재사용
   - 아이콘: MaterialDesign 아이콘 사용
   - 간격: 기존 `Margin`, `Padding` 패턴 따름

2. **MVVM 패턴**:
   - View: XAML만 (로직 없음)
   - ViewModel: CommunityToolkit.Mvvm 사용
   - Command: `RelayCommand`, `AsyncRelayCommand`
   - 바인딩: `ObservableProperty` 특성 사용

3. **참고 화면**:
   - `PropertyListView.xaml` - 그리드 레이아웃
   - `PropertyDetailView.xaml` - 탭 레이아웃
   - `NonCoreView.xaml` - 폼 레이아웃
