Plan 01에서 생성된 QAPopupWindow를 편집 가능하게 확장한다.

**XAML 변경:**

1. DataGrid 열 편집 설정 변경:
   - "질의일자" 열: IsReadOnly=True 유지 (자동 설정이므로 수정 불가)
   - "질의내용" 열: IsReadOnly 제거, Binding에 `UpdateSourceTrigger=PropertyChanged` 추가. 단, 기존 저장된 행(Id != Guid.Empty)은 수정 불가하도록 DataGridTemplateColumn으로 변경:
     - CellTemplate: TextBlock (읽기 전용 표시)
     - CellEditingTemplate: 새 행(Id == Guid.Empty)이면 TextBox, 기존 행이면 TextBlock
     - 또는 더 간단하게: DataGridTextColumn으로 유지하되, 코드비하인드에서 `BeginningEdit` 이벤트로 기존 행의 Question 열 편집을 취소
   - "회신일자" 열: IsReadOnly 제거, Binding=`{Binding AnsweredAt, StringFormat=yyyy-MM-dd, UpdateSourceTrigger=PropertyChanged}`, 편집 가능. EditingElementStyle에 SectionDataGridTextBoxStyle 적용.
   - "답변내용" 열: IsReadOnly 제거, Binding=`{Binding Answer, UpdateSourceTrigger=PropertyChanged}`, 편집 가능. EditingElementStyle에 SectionDataGridTextBoxStyle 적용.

2. 하단 버튼 영역에 추가:
   - "행 추가" 버튼 (MaterialDesignFlatButton, PackIcon Kind="Plus", Click="AddRow_Click")
   - "저장" 버튼 (PrimaryButton 스타일, Content="저장", Click="Save_Click", Padding="24,8")
   - "닫기" 버튼 (기존 SecondaryButton 유지)
   - 버튼 순서: 좌측에 "행 추가", 우측에 "저장" + "닫기"

**코드비하인드 변경:**

1. `AddRow_Click`:
   - 새 PropertyQa 객체 생성: `Id = Guid.Empty` (아직 DB 미저장 표시), `PropertyId = _propertyId`, `CreatedAt = DateTime.Now`, `BorrowerNumber = _borrowerNumber`, `BorrowerName = _borrowerName`, `Question = ""`, `Answer = null`, `AnsweredAt = null`
   - `_qaItems.Add(newQa)` — ObservableCollection에 추가하면 DataGrid에 즉시 반영
   - 추가 후 DataGrid 스크롤을 맨 아래로 이동: `QaDataGrid.ScrollIntoView(newQa)`
   - 추가된 행의 "질의내용" 셀에 포커스: `QaDataGrid.CurrentCell = new DataGridCellInfo(newQa, QaDataGrid.Columns[1])` + `QaDataGrid.BeginEdit()`

2. `Save_Click`:
   - 비동기 메서드 `SaveAsync()` 호출
   - 신규 행 (Id == Guid.Empty) 처리:
     - Question이 비어있으면 건너뛰기 (빈 행 무시)
     - `_qaRepository.CreateAsync(qa)` 호출
     - 반환된 객체의 Id로 _qaItems 내 해당 항목 업데이트
   - 기존 행 (Id != Guid.Empty) 중 변경된 항목 처리:
     - Answer 또는 AnsweredAt이 변경된 행 감지를 위해, 로드 시 원본 스냅샷 `_originalAnswers` (Dictionary<Guid, (string? Answer, DateTime? AnsweredAt)>) 저장
     - 변경된 행: `_qaRepository.UpdateAsync(qa)` 호출
     - AnsweredAt이 null이었다가 Answer가 입력되면 AnsweredAt을 DateTime.Now로 자동 설정
   - 저장 완료 후: 성공 메시지 없이 조용히 완료. `_originalAnswers` 스냅샷 갱신.
   - 에러 발생 시: MessageBox로 에러 표시, 부분 저장된 항목은 그대로 유지

3. `BeginningEdit` 이벤트 핸들러 (DataGrid에 추가):
   - 기존 행(Id != Guid.Empty)의 "질의일자" 열(index 0)과 "질의내용" 열(index 1) 편집 시 `e.Cancel = true`
   - 신규 행(Id == Guid.Empty)의 "질의일자" 열(index 0) 편집 시에도 `e.Cancel = true` (자동 설정)
   - 회신일자/답변내용 열은 모든 행에서 편집 허용

4. `LoadQaDataAsync()` 수정:
   - 데이터 로드 후 `_originalAnswers` 스냅샷 저장

**주의사항:**
- AnsweredAt은 DateTime? 타입이므로, 사용자가 빈 문자열을 입력하면 null, 날짜를 입력하면 파싱. 잘못된 형식 입력 시 무시하고 기존값 유지하는 방어 로직 필요. IValueConverter를 만들어 `NullableDateTimeConverter`로 처리: ConvertBack에서 빈 문자열이면 null, 날짜 파싱 실패 시 DependencyProperty.UnsetValue 반환.
- 정렬은 CreatedAt Ascending 유지 (새 행은 맨 아래에 추가)
- DataGrid의 IsReadOnly="False"로 변경 (개별 셀 제어는 BeginningEdit에서)
