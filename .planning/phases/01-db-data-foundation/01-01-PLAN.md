SQL migration 내용:

```sql
-- property_notes: 물건별 탭별 비고 (1 property + 1 tab = 1 note)
CREATE TABLE IF NOT EXISTS property_notes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  property_id UUID NOT NULL REFERENCES properties(id) ON DELETE CASCADE,
  tab_name TEXT NOT NULL,
  note_text TEXT NOT NULL DEFAULT '',
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),

  CONSTRAINT uq_property_notes_property_tab UNIQUE (property_id, tab_name)
);

-- 인덱스: property_id로 전체 비고 조회 최적화
CREATE INDEX IF NOT EXISTS idx_property_notes_property_id ON property_notes(property_id);

-- RLS 활성화
ALTER TABLE property_notes ENABLE ROW LEVEL SECURITY;

-- RLS 정책: 인증된 사용자 전체 접근 (기존 properties 테이블과 동일한 패턴)
CREATE POLICY "Authenticated users can read property_notes"
  ON property_notes FOR SELECT
  TO authenticated
  USING (true);

CREATE POLICY "Authenticated users can insert property_notes"
  ON property_notes FOR INSERT
  TO authenticated
  WITH CHECK (true);

CREATE POLICY "Authenticated users can update property_notes"
  ON property_notes FOR UPDATE
  TO authenticated
  USING (true)
  WITH CHECK (true);

CREATE POLICY "Authenticated users can delete property_notes"
  ON property_notes FOR DELETE
  TO authenticated
  USING (true);
```

Migration name: `create_property_notes_table`

**2. PropertyNoteRepository 생성** (`src/NPLogic.Data/Repositories/PropertyNoteRepository.cs`):

기존 AuditLogRepository 패턴을 따른다:
- `SupabaseService` 생성자 주입
- `PropertyNoteTable` 내부 클래스 (Postgrest.Models.BaseModel 상속, `[Table("property_notes")]`)
- `MapToPropertyNote` / `MapToTable` 매퍼 메서드

메서드 4개:

(a) `GetByPropertyIdAsync(Guid propertyId)` → `Task<List<PropertyNote>>`
  - `Where(x => x.PropertyId == propertyId)` 로 해당 물건의 전체 비고 조회
  - `Order(x => x.TabName, Ascending)` 으로 탭 이름순 정렬

(b) `GetByPropertyAndTabAsync(Guid propertyId, string tabName)` → `Task<PropertyNote?>`
  - 두 조건 Where로 단일 비고 조회
  - `.Single()` 또는 `.Get()` 후 `.FirstOrDefault()` 사용

(c) `UpsertAsync(PropertyNote note)` → `Task<PropertyNote>`
  - `note.UpdatedAt = DateTime.UtcNow` 설정
  - `note.Id`가 `Guid.Empty`이면 `gen_random_uuid()`에 의해 자동 생성되므로 새 Guid 할당
  - Postgrest의 `.Upsert()` 사용 (property_id + tab_name 유니크 제약에 의해 ON CONFLICT 동작)
  - 주의: Upsert 시 PropertyNoteTable 매핑 후 사용

(d) `DeleteAsync(Guid noteId)` → `Task`
  - `Where(x => x.Id == noteId).Delete()` 로 삭제

에러 처리: 각 메서드를 try/catch로 감싸고, `throw new Exception($"비고 {작업} 실패: {ex.Message}", ex)` 형태 (기존 패턴).
